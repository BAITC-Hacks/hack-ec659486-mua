# Runbook 23.09 — шаги и промпты, только GUI

Нейросети запускаются только в приложениях: **Codex** (десктоп, режим Full access / без подтверждений) и **Claude Code** (вкладка Code, режим Auto). Терминал нужен только для git и скриптов. Один агент = одно окно = одна папка worktree = одна ветка. Автономные сессии закрываются сами: их промпт заканчивается блоком «до зелёного Done-when» — агент сам гоняет команду, коммитит, пушит ветку и пишет отчёт `status/agents/SNN.md`. Человек читает отчёт, сам запускает Done-when (30 секунд) и ставит ветку в мерж-поезд.

## Если что-то пошло не так

- Агент в GUI завис или молчит 2 минуты — проверить сеть `ping 1.1.1.1`; перезапустить окно с тем же промптом и добавить: «Продолжи: вот что уже сделано в ветке» (`git log --oneline -n 5`).
- Лимит Codex у A — запускать окна с аккаунта B, или Claude Code с тем же промптом (`new-session.sh <ветка> claude`).
- Красный мерж-поезд — ветка откатывается, чинится в своём worktree, едет следующим поездом. `main` не чинить.
- `LLMError: нет фикстуры mocks/...` в mock-режиме — хэш payload изменился; владелец модуля обновляет свою ручную фикстуру, или S15 перезаписывает живым ответом.
- Не хватает времени — резать по `docs/sessions.md` («Честно про пределы»): S20 → иллюстрации S19 → smoke S17 → таймаут S16 → Cut-if S14 → Cut-if S11. Ядро S01→S04→S05→S08→S09→S10→S12→S14 не резать.
