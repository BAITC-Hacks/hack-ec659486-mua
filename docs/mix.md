# Микс: три сессии-собеседника на человека + автономные кодеры в цикле

Решение 23.09 10:40, уточнение 11:00: **нейросети только в GUI** (Codex app, Claude Code), CLI-циклы не используем; автономность встроена в промпты сессий (блок «до зелёного Done-when»). Пошаговый лист с промптами — `docs/runbook-gui.md`. Люди не пишут код руками и не читают по 6 агентов. У каждого **три интерактивные сессии**, с которыми он разговаривает, а код пишут **автономные агенты в GUI**: окно Codex в своём worktree с промптом `prompts/sessions/SNN-*.md`, который заканчивается блоком «работай до зелёного Done-when»: агент сам гоняет команду, коммитит на свою ветку, пушит её и оставляет отчёт в `status/agents/SNN.md`. Волны, матрица владения файлами и мерж-поезд — из `docs/sessions.md`, промпты — `prompts/sessions/`.

## Автономные кодеры (GUI)

Запуск: `scripts/ops/new-session.sh s/parser codex` → Codex app → открыть папку `../wt-parser` → Full access → `scripts/ops/prompt.sh S04` → вставить. Дальше окно не трогать до отчёта `status/agents/S04.md`. Красный отчёт → открыть тот же worktree и дожать в диалоге (это работа A1/B2). Сессии без команды в Done-when (S11, S18, S19, S20, S22) — интерактивные.

Бюджет: окна A — с аккаунта A, окна B — с аккаунта B (два бюджета Codex). Claude Code — для штурмана A3, данных A2, интегратора B1 и как замена Codex при лимите.
