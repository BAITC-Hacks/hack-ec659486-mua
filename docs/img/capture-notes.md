## Съёмка и проверка

Снимки сделаны браузером через CUA с реальных страниц `/`, `/runs/{id}`,
`/report/{id}`. Для длинных экранов использована область страницы заданной высоты.
DOM, ответы API, подписи и числа не менялись. Растр перекодирован в PNG с палитрой
до 256 цветов для соблюдения лимита 500 000 байт; содержимое не ретушировалось.
Схема растеризована из SVG имеющейся зависимостью `sharp`; зависимостей не добавлено.

Runtime и временная копия неизменённого frontend размещены в `.capture/` внутри
`docs/img/`, исключены из Git. Использованы уже установленные зависимости проекта.
Секреты и персональные пути не выводились в интерфейс. Визуально проверены
опубликованные кадры; хэши проверенных PNG записаны в `capture-manifest.json`.

Команда Done-when из корня:

```bash
python3 docs/img/check_assets.py
```

Команда проверяет PNG-сигнатуру, CRC, распаковку пикселей, отсутствие текстовых
метаданных, лимит размера, соответствие визуально проверенным хэшам и ссылки
из корневого README. Отсутствие ссылок S18 возвращает `NOT READY`, а не ложный PASS.
Автоматическая проверка не заменяет визуальный просмотр на секреты и личные данные.

Для нового комплекта: сначала завершить mock-прогон до `done`, снять те же страницы,
проверить каждый PNG визуально, обновить происхождение и хэши в manifest, затем
повторить команду после добавления ссылок S18.
