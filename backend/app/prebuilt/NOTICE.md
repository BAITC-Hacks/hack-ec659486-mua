# Заранее подготовленные компоненты (раскрытие по Положению 5.4.4 / 5.4.4.2)

`lib_docx.py` и `lib_normalize.py` — внутренние утилиты команды, написанные до хакатона для других задач вуза
и скопированные сюда без изменений:

- `lib_docx.py` — детерминированный разбор .docx (только stdlib: zipfile, re): абзацы, списки, сегментация по разделам.
- `lib_normalize.py` — нормализация формулировок функций (stdlib: re): природа работы, класс глагола, объект, сигнатура.

Это инфраструктурные утилиты без логики сравнения «до/после», без LLM и без интерфейса.
Основная функциональность агента (подразделения, сопоставление функций, потери, дубли, конфликты интересов,
заключение с источниками) разработана 23.09.2026 в рамках соревновательной части.
