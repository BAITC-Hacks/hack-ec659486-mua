# Кэш эмбеддингов (dense-ранг кандидатов, `app/candidates.py`)

Здесь лежат векторы `text-embedding-3-small` для текстов функций. Dense-ранг опционален:
он только участвует в слиянии рангов RRF при поиске кандидатов и никогда не ставит статус
(порог косинуса решением не является — 0,85 давал 44 ложных дубля из 150).

## Файл

Имя — `{sha256(text)}.json`, где `text` — текст функции в UTF-8 как есть (для дублей — текст
без шаблонных оборотов, см. `candidates.strip_templates`).

```json
{"model": "text-embedding-3-small", "text_sha256": "<sha256 текста>", "vector": [0.0123, -0.0456, ...]}
```

Файл с другой моделью или чужим `text_sha256` игнорируется.

## Как пополняется

- `LLM_MODE=live` и непустой `OPENAI_API_KEY`: `candidates.embed` запрашивает недостающие векторы
  (`client.embeddings.create`, пакеты ≤ 100 текстов) и пишет их сюда.
- `LLM_MODE=mock` или ключа нет: читается только кэш; нет вектора — dense для этой функции
  пропускается без ошибки, работают лексический ранг (BM25) и сигнатура.

Сейчас векторов нет: тесты и mock-прогон идут без dense. S15 может добавить векторы тестового
комплекта живым прогоном с ключом.
