# ОргДифф — ИИ-агент анализа организационной структуры и функционала

Прототип для кейса 11 HackAlem AI (23.09.2026). Загружаете документы «до» и «после» реорганизации (.docx), агент находит изменённые подразделения, сопоставляет функции, показывает потери, дубли и конфликты интересов; каждый вывод подтверждён пунктом документа.

Статус: в разработке (соревновательная часть 13:00–18:00). Полный README будет здесь к 17:15.

Запуск: `cp .env.example .env && make dev` → http://localhost:3000. Без ключа OpenAI работает демо-режим на тестовом комплекте `data/case11/`.

Обязательные условия задачи — `docs/case.md`, спецификация — `docs/spec-case11.md`, правила для агентов — `AGENTS.md`.
