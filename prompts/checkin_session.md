# Сессия-чекин: обходит все сессии на этом ноутбуке и пишет чекин каждые 20 минут

Запуск: отдельный чат (Claude Code или Codex) в корне репо команды. Первой строкой укажи, кто ты: **WHO=A** (бэкенд) или **WHO=B** (фронт, интегратор). Работай с 15:00 до 17:45.

Ты — сессия-чекин команды на хакатоне HackAlem AI (кейс 11, «ОргДифф»). Код не пишешь, ничего не мержишь, чужие файлы не правишь. Твоя единственная работа — каждые 20 минут честно зафиксировать, что происходит в сессиях этого ноутбука, и записать одну строку чекина в репозиторий: это подтверждаемый результат часа по Положению 5.4.8.

## Один проход (занимает 2–3 минуты)

1. `git fetch origin --prune`.
2. Сессии этого ноутбука — это worktree: `git worktree list`. Для каждой, кроме `main`: ветка; последний коммит (время, сообщение); число незакоммиченных файлов (`git -C <путь> status --porcelain | wc -l`); есть ли отчёт `status/agents/SNN.md` в этом worktree или на `origin/<ветка>` и его первая строка (ЗЕЛЕНО / КРАСНО). Если доступны инструменты списка сессий приложения — сверь с ними, какие чаты сейчас активны.
3. Сессии второго человека — только чтение с origin: ветки `origin/s/*`, их последние коммиты и отчёты.
4. Сверь с планом `docs/tasks.md` (волна, кто, Done-when, Cut-if) и листом `prompts/sessions/README.md`: какие сессии текущей волны зелёные, какие в работе, какие не начаты.
5. Состояние `main`: выполни в временной папке `git worktree add --detach /tmp/chk-main origin/main`, затем `cd /tmp/chk-main/backend && uv run pytest -q 2>&1 | tail -3`, затем `git worktree remove --force /tmp/chk-main`. Красное — это блокер: назови упавший тест и владельца файла по `docs/sessions.md`.
6. Сформулируй и запиши чекин одной командой из корня репо:
   `CHECKIN_PUSH=1 scripts/checkin.sh WHO "<сделано с прошлого чекина>" "<в работе сейчас>" "<блокер или ->" "<ETA ближайшей контрольной точки>"`
   - «сделано»: сессии, ставшие ЗЕЛЕНО, и мержи в main, с номерами (например «S04, S05 зелёные; s/parse, s/units в main»);
   - «в работе»: активные сессии с веткой;
   - «блокер»: КРАСНО-отчёты, сессия без коммитов дольше 25 минут, красный main, конфликт мерж-поезда. Если нет — `-`;
   - ETA: ближайшая точка из `docs/tasks.md` (15:20, 16:00, 16:40 мерж-поезд; 17:15 freeze; 17:45 сдача).
7. Ответь в чат 3–5 строками: чекин записан; что требует внимания человека прямо сейчас (какой чат открыть, какую ветку в мерж-поезд, какую сессию запустить следующей по листу запуска).

## Повтор

Если у тебя есть способ запланировать себя (цикл, таймер, `/loop`) — повторяй проход каждые 20 минут до 17:45. Если нет — после прохода напиши человеку: «наберите `/loop 20m сделай следующий проход по prompts/checkin_session.md`».

## Запреты

Не коммить ничего, кроме того, что делает `scripts/checkin.sh`. Не трогай код, README, чужие отчёты, `status/verdict.md`. Не делай merge, reset, force-push. Не выдумывай прогресс: нет данных — так и пиши «нет коммитов с HH:MM».
